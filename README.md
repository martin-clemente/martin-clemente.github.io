## Running locally

Clone the repo and open `index.html` directly in a browser — no server or build tools needed.

```bash
git clone https://github.com/martin-clemente/martin-clemente.github.io.git
cd martin-clemente.github.io
open index.html   # or just double-click the file
```

## Deployment

Hosted with GitHub Pages from the `main` branch, root folder (`/`). Any push to `main` updates the live site.
