Proyecto destacado

AirSense

Proyecto colaborativo

Sistema de monitoreo ambiental construido para comprender mejor las condiciones interiores/exteriores mediante recolección y visualización de datos en tiempo real. Registra temperatura, humedad, ruido ambiental y CO₂ con sensores basados en ESP32, con un panel web para visualización y alertas, más análisis asistido por IA para respaldar recomendaciones. AirSense compitió en ACTE 2026 y avanzó a una segunda instancia.

Mi contribución

Diseñé y construí el dashboard y toda la página web: el panel de visualización de datos con alertas, más el frontend integrado con los datos de los sensores basados en ESP32.

Proyecto colaborativo

WRC26

WRC26 es un sistema de gestión de entradas para el Mundial FIFA 2026 (Canadá · México · EE. UU.). Desarrollado con Django, permite ver los 48 equipos, los partidos de fase de grupos y los 16 estadios sede en un mapa interactivo con Leaflet.js, comprar entradas con un carrito de compras y gestionar las compras.

Mi contribución

Estuve a cargo del frontend: diseñé y construí todas las plantillas HTML/CSS, el mapa interactivo de estadios con Leaflet.js, las interacciones en JavaScript y las validaciones de formularios del lado del cliente, integradas con el backend de Django.

  • Leaflet.js

Proyecto

Arcson Bridge

Sitio web institucional de Bridge Arcson, desarrollado con Django. El diseño sigue el manual de identidad de la empresa (paleta de colores, tipografías Montserrat / Open Sans) y presenta todo el contenido del producto — ArcBridge One IoT — en las páginas de inicio, producto, empresa y contacto con formulario.

Mi contribución

Diseñé y construí el sitio completo: la identidad visual aplicada a partir del manual de marca, el frontend de todas las páginas y la integración con Django, con todo el texto institucional centralizado en un único archivo de contenido para editar fácilmente.
